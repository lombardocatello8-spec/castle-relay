MULTIPLAYER

Co-op dungeon crawl — online multiplayer, no tunnel needed.
Option A — Cloud relay (recommended):
Deploy server.js to Railway or Render (free tier). You get a permanent wss:// URL everyone pastes — no local server, no tunnel, always on.
Railway: push the repo → New Project → Deploy → copy the wss:// domain.

Option B — Local + Cloudflare Tunnel (no account needed):
1. npm install ws && node server.js
2. cloudflared tunnel --url ws://localhost:8080
3. Copy the *.trycloudflare.com URL, change https → wss, paste below.

Both options: HOST enters the wss:// URL and clicks HOST GAME. Share the 5-letter room code with friends. Joiners paste the same URL + code, click JOIN GAME. Up to 4 players.
Endless: crawl forever, cycles loop. Story: 10 dungeons + princess rescue with teammates. Up to 4 players.
